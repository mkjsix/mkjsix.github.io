Three levels of design

Architecture

Architecture sets the boundaries between components and the patterns that connect them, such as microservices or event-driven integration. Once the system is in production, it is the hardest part of the design to change.

System design

System design maps the logical architecture onto cloud or on-premises infrastructure. It decides how the system handles traffic peaks and server failures.

Software design

Software design is the structure of the code inside each component. I write it test-first and refactor it continuously, and every change goes through continuous integration. Code written by AI agents goes through the same tests before it is merged.
